# rag/manual 청크 파일 형식

`hana_deposit_product_sheet.md`는 상품설명서 본문이 거의 그대로 들어 있어 git에 올리지 않는다.
다시 만들려면 하나은행 상품공시실에서 『하나의 정기예금』 상품설명서를 받아 아래 형식으로 항목별로 정리한다.

## 형식

- `### [키] 속성=값 | 속성=값` 으로 시작하는 줄이 청크 하나의 시작이다. 이 줄부터 다음 `###` 줄 전까지가 본문이다.
- 파일 맨 위의 설명(이 문서처럼)은 읽지 않는다.
- 속성은 `chunk_type`(청크 종류), `section`(문서 안 위치), `page`(쪽, 선택), `cleaned=true`(표를 손질한 청크)를 쓴다.
- 본문은 원문 문구를 그대로 두고, 줄바꿈과 표 모양만 정리한다. 표는 마크다운 표로 바꾼다.

## 권장 청크 (키 : chunk_type)

| 키 | chunk_type | 내용 |
| --- | --- | --- |
| overview | 상품개요 | 상품명, 가입대상, 가입금액, 계약기간, 거래방법, 이자지급방식 |
| rates | 금리 | 기본금리와 적용금리의 정의, 쿠폰 우대금리 적용 범위 |
| early_termination | 중도해지 | 중도해지금리 산출근거 문장, 구간표, 차등율 · 경과율 주석, 절사 규칙 (계산에 한꺼번에 필요하므로 한 청크) |
| after_maturity | 만기후금리 | 만기 후 금리 산식 |
| interest_calc | 이자계산_일반 | 일반 이자계산방법 (중도해지 계산과 구분하기 위해 따로 둔다) |
| partial_withdrawal | 일부해지 | 일부해지 조건 |
| renewal | 재예치 | 재예치(갱신) 방식과 불가 사유 |
| cancel_method | 계약해지방법 | 해지 채널, 만기가 휴일인 경우의 처리 |
| payment_restriction | 원금이자지급제한 | 압류 등으로 인한 지급 제한 |
| tax, collateral, deposit_protection | 세제혜택, 양도담보, 예금자보호 | 항목별 한 청크 |
| dormant, illegal_contract, data_access | 휴면예금, 위법계약해지권, 자료열람요구권 | 항목별 한 청크 |
| glossary_elapsed, glossary_other | 용어 | 부록의 용어 설명 (경과기간 정의는 따로) |

## 예시 (본문은 자리표시)

```
### [early_termination] chunk_type=중도해지 | section=거래 조건 > 중도해지금리 | cleaned=true
(중도해지금리 산출근거 문장)

| 기간 | 중도해지금리 |
| --- | --- |
| (구간) | (금리 또는 산식) |

(주1) ... (주2) ... ※ (절사 규칙)
```

같은 표가 문서의 요약 쪽과 상세 쪽에 두 번 나와도 한 청크로 합친다.
