# 도구를 잘못 고른 사례 (실제 모델 qwen2.5:7b)

검증용 20문항(`eval/heldout/questions.json`)의 실제 모델 실행 기록에서 모았다. 앞으로는 `python -m app.traces list --signals`로 후보를 찾고,
`python -m app.traces mark ID wrong_tool --note "…"` → `python -m app.traces export`로 이 형식의 사례를 뽑는다.
기록 출처: 수정 전 `before_fix`(2026-10-28), 수정 후 `after_fix` · `after_evidence`(2026-10-29). 답변 본문은 싣지 않는다.

## 읽는 법

- 1~8번과 10번은 코드로 막았다. 코드는 계산에 넘기는 값과 답변을 지키고, 모델의 도구 선택 자체를 바꾸지는 못한다(2번은 수정 후에도 모델이 계속 지어낸다).
- 9번은 틀린 정보가 나오지 않아 두고 있지만, 사용자는 규칙 설명 대신 값을 되묻는 답을 받는다. 실제 사용에서 얼마나 자주 나오는지 `calc_on_rule_question` 신호로 센다.
- 표는 20문항 기준이라 건수가 적다. 같은 문항을 보고 고친 것이라(1~8번) 일반화 증거가 아니다.
